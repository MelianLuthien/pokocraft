# Changelog

## 1.0.1

- Adds a Linux x64 build, for Recompia on Linux and Steam Deck.
- No changes to how the mod behaves.

## 1.0.0

First public release.

- Crafting never consumes materials.
- **Bypass Requirements** setting (default on): craft with an empty bag and pick
  any quantity up to 99. When off, the game checks your bag as usual.
- Nothing is added to the player's bag, and no game files are included.
